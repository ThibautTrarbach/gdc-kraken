Récupération de l'historique des missions

Envoyez les fichiers .pbo présents dans le cache Arma 3 de votre PC. Les nouvelles missions seront rattachées au compte GDC-RECUP. Si la mission existe déjà en base (même sans fichier PBO), le PBO sera restauré sans changer le propriétaire.

Où trouver les fichiers missions sur votre PC ?

  • Cache multijoueur (le plus courant) :
    %LOCALAPPDATA%\Arma 3\MPMissionsCache\
    En explorateur Windows : collez ce chemin dans la barre d'adresse, ou ouvrez C:\Users\VOTRE_NOM\AppData\Local\Arma 3\MPMissionsCache\
  • Missions éditeur / locales :
    %USERPROFILE%\Documents\Arma 3\mpmissions\
  • Format de nom attendu : CPC-Type[XX]-Nom-VY.map.pbo (ex. CPC-CO[20]-MaMission-V2.altis.pbo)
  • Les missions incomplètes (sans HC, SQM binarisé, briefing manquant) sont acceptées ici ; un nom de fichier hors format est refusé.
